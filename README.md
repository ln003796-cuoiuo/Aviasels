# Эволюция — симулятор мира

Android WebView-приложение с локальной браузерной симуляцией раннего мира.

## Сборка APK
1. Открой вкладку **Actions**.
2. Выбери **Build Android APK**.
3. Открой последний успешный запуск.
4. В разделе **Artifacts** скачай `Evolution-debug-apk` (в старых запусках имя может быть `AviaTrip-debug-apk`).
5. Распакуй архив и установи APK на Android. Для установки может потребоваться разрешить установку из выбранного источника.

## Реализовано в текущем прототипе
- Два начальных жителя с характеристиками, потребностями, памятью и текущими целями.
- Автоматическое течение дней, пауза и ускорение.
- Режимы долины, комнаты, планеты и космоса (визуализация 2D).
- Создание леса, реки, горы, озера, храма, дома, поля и базы на Марсе.
- Команды создателя, изменение климата, журнал событий, отмена изменений объектов.
- Простой шаблонный диалог и выдача поручения жителю.
- Локальные сохранения, экспорт и импорт JSON.

## Ограничения
Это ранний игровой прототип, а не полноценная научная модель. Диалоги пока шаблонные; люди не обладают настоящим свободным интеллектом. Родословные, реалистичная 3D-сцена, физика, полноценная экономика, настоящие миссии на Марс и LLM-интеграция ещё не реализованы. Визуализация комнаты — игровая сцена, не видеонаблюдение.
